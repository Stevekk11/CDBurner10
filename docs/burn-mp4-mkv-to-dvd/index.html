How to Burn MP4 & MKV to a Playable Video DVD

Copying an MP4 file directly to a data disc will not play on most standalone DVD players. CDBurner10 authors a compliant DVD-Video UDF 1.02 bridge disc in PAL or NTSC — with crisp, unstretched subtitles.

Download CDBurner10 v10.5.9 (Free)

Step-by-Step: MP4/MKV to Video DVD

  1. Install CDBurner10 & FFmpeg
    Install CDBurner10-10.5.9-win-x64.msi and make sure ffmpeg is available on your PATH (winget install Gyan.FFmpeg).
  2. Open "DVD from File"
    In CDBurner10's navigation sidebar, select DVD from File (or Video DVD if you already have a VIDEO_TS folder).
  3. Add MP4/MKV files & select subtitles
    Add your video files. CDBurner10 supports embedded subtitles (SRT, ASS, mov_text, WebVTT, VobSub, PGS, DVB) as well as external .srt files. As of v10.5.9, subtitles are rendered onto a square-pixel frame before anamorphic PAL/NTSC scaling so text is never stretched.
  4. Pick PAL/NTSC and burn
    Insert a blank DVD-R or DVD+R, choose PAL (Europe/Australia) or NTSC (North America/Japan), enable post-burn verification if desired, and click Burn.
